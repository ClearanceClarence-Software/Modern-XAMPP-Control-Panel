After the download

  • Unzip XamppControl.exe anywhere; next to xampp-control.exe in C:\xampp is the obvious place.
  • Run it. It finds XAMPP in its own folder, the folder above, or C:\xampp, and asks if it is somewhere else.
  • To find it from Windows search, tick Config › Show in the Start menu.
  • Later versions install from inside the panel: the header shows when one is out.

Good to know

  • You need a XAMPP for Windows, any recent version. The panel does not include Apache, MariaDB or PHP.
  • SmartScreen may warn about an unrecognized app the first time. Choose More info › Run anyway.
  • The exe is code-signed. How to check the signature.
  • Prefer to build it yourself? See Building from source.
